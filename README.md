## 编译
环境要求：JDK 21

```bash
# 克隆仓库
git clone https://github.com/911q2w3e1q/Nexus.git
cd Nexus

# 编译
./gradlew build
```

编译好的 jar 会在 `build/libs/` 目录下。

## 下载
去 [Releases](https://github.com/911q2w3e1q/Nexus/releases) 页面下载对应版本的 jar 文件。
